# vite-plugin-debug-meta

Легковесный и мощный Vite-плагин для React, внедряющий отладочные метаданные в JSX/TSX элементы на этапе разработки. Позволяет зажать `Ctrl + Shift`, навести на любой элемент, прокрутить колесо мыши для навигации по иерархии компонентов и кликнуть для мгновенного открытия файла в вашей IDE на нужной строке.

---

## 🚀 Основные возможности

### 🔍 1. Интерактивный режим инспектирования (`Ctrl + Shift` + наведение)
* **Интеллектуальная подсветка:** При зажатии `Ctrl + Shift` элементы подсвечиваются рамкой, а рядом отображается плавающий бейдж с именем компонента и его точными размерами в пикселях.
* **Блокировка выделения:** На время инспектирования на странице временно отключается выделение текста (`user-select: none`), предотвращая случайное выделение блоков.
* **Поддержка заблокированных элементов:** Инспектирование корректно работает на элементах с атрибутом `disabled` или классом `.disabled` (их `pointer-events` временно отключаются, чтобы они не мешали наведению).
* **Всплывающие подсказки (Native Tooltips):** Плагин временно подменяет атрибут `title` у наведенного элемента на относительный путь к файлу с номером строки (например, `src/components/Button.tsx#24`), аккуратно возвращая оригинальный `title` после выхода из режима инспекции.

### 🎡 2. Навигация по иерархии React-компонентов (Скролл мыши)
* **Путешествие по React Fiber:** Находясь в режиме инспекции над элементом, прокручивайте колесо мыши (`wheel`), удерживая `Ctrl + Shift`, чтобы перемещаться вверх и вниз по дереву компонентов (от целевого DOM-узла к его родительским компонентам).
* **Хлебные крошки (Breadcrumbs):** В плавающем бейдже в реальном времени отрисовывается путь хлебных крошек (например, `App > PageLayout > Header > Button`) с визуальной подсветкой текущего выбранного уровня.
* **Динамическая рамка подсветки:** При перемещении по иерархии на странице отображается синяя штриховая рамка вокруг DOM-узла, соответствующего выбранному в данный момент родителю. Рамка перемещается и меняет размер с плавной анимацией (`transition`).

### 🖱️ 3. Быстрый переход в IDE (`Ctrl + Shift` + Клик)
* Клик левой кнопкой мыши с зажатыми `Ctrl + Shift` мгновенно открывает исходный код выбранного компонента (с учетом выбранного скроллом уровня в иерархии) в вашей IDE на нужной строке.

## 📦 Установка

Установите пакет в качестве dev-зависимости с помощью вашего пакетного менеджера:

```bash
npm install -D vite-plugin-debug-meta
# или
yarn add -D vite-plugin-debug-meta
# или
pnpm add -D vite-plugin-debug-meta
```

---

## ⚙️ Использование

Добавьте плагин в конфигурационный файл `vite.config.ts` или `vite.config.js`:

```typescript
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import { debugMetaPlugin } from "vite-plugin-debug-meta";

export default defineConfig({
  plugins: [
    react(),
    debugMetaPlugin({
      // Необязательно: укажите предпочитаемый редактор по умолчанию.
      // Если не указано, плагин попытается автоматически определить IDE 
      // или будет использовать переменную окружения LAUNCH_EDITOR.
      editor: "code"
    })
  ]
});
```

### Параметры конфигурации

| Параметр | Тип | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `editor` | `string` | `undefined` | Название редактора для открытия файлов (например, `"code"` для VS Code, `"antigravity-ide"`, `"cursor"`, `"webstorm"`, `"zed"` и др.). |

## 🛠️ Как это работает под капотом

1. **Babel AST Трансформация:** Плагин перехватывает `.tsx`/`.jsx` файлы на этапе `transform` в Vite. Он парсит код в AST (Abstract Syntax Tree), находит открывающие JSX-теги (пропуская фрагменты и сторонние библиотеки) и автоматически внедряет атрибуты `data-debug-file` (относительный путь к файлу и строка) и `data-debug-component` (название компонента).
2. **Интеграция с Vite Server и поддержка кастомных IDE:**
   * Для стандартных редакторов (таких как VS Code, WebStorm и др.) плагин использует встроенный в Vite эндпоинт `/__open-in-editor`, проксирующий запуск в пакет `launch-editor`.
   * Для специализированных редакторов (таких как **Antigravity IDE** — `"antigravity"` / `"antigravity-ide"`) или любых других кастомных путей к редактору плагин перехватывает запрос и напрямую запускает процесс через `child_process.spawn` с флагом `-g` для позиционирования на строке (например, `editor -g path/to/file:line:1`).
3. **Клиентский интерактивный скрипт:** В HTML-код страницы инжектируется легковесный JS-скрипт и CSS-стили. Скрипт отслеживает клавиатурные события и жесты мыши, опрашивает React Fiber дерево (для получения точной иерархии компонентов при прокрутке колеса мыши) и отправляет запрос на открытие файла в Vite.
